# Evidence and Citation Rules

1. Cite each important factual claim close to the claim.
2. Use the source's actual title, publisher, publication date, and URL when available.
3. For uploaded PDFs, cite the actual page number only when it can be identified.
4. Never invent source names, URLs, page numbers, quotations, statistics, or sample sizes.
5. Distinguish direct evidence from interpretation and recommendations.
6. Preserve population, geography, time period, sample, and measurement definitions.
7. Do not compare unlike measures (for example, AI experimentation versus production deployment).
8. Mark evidence as Verified, Partially Verified, or Unverified according to what was actually checked.
9. If a source cannot be accessed, say so. Do not treat a search snippet as full-source verification.
10. A Strategist recommendation must be traceable to one or more Analyst findings.
11. Label proposed targets and expected benefits as proposals, not achieved outcomes.
12. Synthetic test data is only for workflow testing and must never be cited as real-world evidence.
